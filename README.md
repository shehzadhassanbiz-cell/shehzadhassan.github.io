# Portfolio – Muhammed Shehzad Hassan

Structural integrity simulation portfolio: FEA of composite and metallic structures, each model validated against hand calculations.

## Put it online with GitHub Pages (free)

1. Create a free account at github.com (username suggestion: `shehzadhassan`).
2. Click **New repository** and name it exactly `<your-username>.github.io`, for example `shehzadhassan.github.io`. Set it to **Public**.
3. Click **Add file → Upload files** and upload:
   - `index.html`
   - `README.md`
   - your CVs as `CV_Shehzad_Hassan_EN.pdf` and `CV_Shehzad_Hassan_DE.pdf`
   - the `images` folder with the files listed below
4. Click **Commit changes**.
5. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, branch `main`, folder `/ (root)`, then **Save**.
6. After 1–2 minutes the site is live at `https://<your-username>.github.io`.

## Images to upload (folder `images/`)

Use exactly these file names. Until an image is uploaded, the page shows a labelled placeholder in its place.

| File name | What it shows |
|---|---|
| `P2_layup.png` | ACP sampling point layup plot (8 plies) |
| `P2_engineering_constants.png` | ACP Engineering Constants window (47,036 MPa) |
| `P2_strain.png` | Normal elastic strain X, layer 4 top (butterfly shape) |
| `P2_IRF_full.png` | Inverse Reserve Factor contour, labels off |
| `P1_stress.png` | Normal stress (X) contour, 1 mm or 0.5 mm mesh |
| `P1_mesh_hole.png` | Mesh zoomed in at the hole |
| `CFD_comparison.png` | Figure 17 from the OpenFOAM report (measured vs simulated water levels) |

Tip: crop screenshots to the model and keep them under about 1 MB each.
